# agent-friend-guide

面向用户与 Coding Agent 的 agent-friend 产品知识 Skill。它回答产品功能、使用方法、模型与在线工具凭据、语音凭据、数据隐私和常见排障问题。

## 安装

Skill 位于：`skills/agent-friend-guide`

支持从 GitHub 仓库路径安装 Skill 的 Coding Agent，可使用仓库 `A1m233/agent-friend-guide` 和上面的 Skill 路径。也可以把该目录复制到 Agent 的个人 Skill 目录。

## 内容原则

- 中文内容是首版权威版本。
- 只记录用户需要的产品知识，不公开内部实现与维护流程。
- 第三方平台只提供对应能力所需的最短申请路径，并链接官方文档。
